# TraderFrost Website

A scalable static website structure for the TraderFrost trading education platform.

## Structure
- **index.html**: Home page
- **pages/**: Secondary pages (about, courses, psychology, contact, batches, search results)
- **assets/**: Images, fonts, videos
- **css/**: Base, layout, and component styles with a unified `main.css`
- **js/**: Core, component, and page scripts with a unified `main.js`
- **backend/**: Placeholder structure for future backend integration

## Run
Open `index.html` in a browser or use a static server.

## Notes
All links, scripts, and assets are path-updated to work with this structure.
